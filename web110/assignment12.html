Assignment 12 Summary

In this session I was able to play around with JavaScript a little bit more. So far in the semester, I have been introduced to HTML to help build a web page and CSS to play around with fonts and backgrounds as well as adding photos, video, audio and YouTube links. By working through this session's activities, I was able to see how JavaScript helps make my web page more interactive instead of just a page to scroll through. This week I was able to put my name in a heading and to show the current date and time. The date and time adjust automatically based on the time zone of whoever is viewing the page, so the visitor will see their time and not mine. I also learned that each part of a web page can have an id, and that is how JavaScript knows which element it needs to find and edit. I'm still new to using JavaScript, but this lesson gave me a beginner's understanding of it. I enjoyed trying out buttons that change text when you click them. In an IT position, understanding how to read a script would help with troubleshooting errors or figuring out why things aren't showing up.
